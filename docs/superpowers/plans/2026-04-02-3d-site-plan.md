# 3D Site Plan — React Three Fiber Implementation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current 2D SVG/PNG overlay site plan page with a full 3D interactive floor plan using React Three Fiber, matching the quality of the grove-house-3d.html reference.

**Architecture:** Three dedicated component files — a 3D room data module, a React Three Fiber scene component, and the page wrapper with UI chrome (toolbar, room panel, overlays). The scene uses OrbitControls from drei, raycasting for room clicks, and framer-motion for panel animations. Room data is derived from the existing grove-house-site-model.ts with 3D coordinates added.

**Tech Stack:** React Three Fiber (`@react-three/fiber`), drei (`@react-three/drei`), Three.js (already installed), Framer Motion (already installed), Tailwind CSS, Next.js App Router.

### Task 3: Build React Three Fiber Scene Component

**Files:**
- Create: `apps/platform/src/components/show-me-site/GroveHouse3DScene.tsx`

This is the core 3D component. It renders inside an R3F `<Canvas>` and contains:

1. **Ground plane** — dark navy (#1a2332) with grid overlay
2. **Playground/tarmac/field** — coloured ground areas
3. **Room meshes** — for each room: floor slab, 4 transparent glass walls, wireframe edges, roof, base compliance strip
4. **Labels** — sprite text above each room (using drei `<Text>`)
5. **Fire exits** — door markers with green/amber sprites
6. **Fire routes** — red animated dot lines (shown on toggle)
7. **Fire equipment** — extinguisher cylinders (shown on toggle)
8. **Compliance overlay** — colour-coded floor overlays (green/amber/red)
9. **OrbitControls** — drag to orbit, scroll to zoom, auto-rotate when idle
10. **Raycasting** — click room floors to trigger `onRoomClick` callback

Props interface:
```typescript
interface GroveHouse3DSceneProps {
  onRoomClick: (room: Room3D) => void;
  showWalls: boolean;
  showRoof: boolean;
  showCompliance: boolean;
  showXray: boolean;
  showLabels: boolean;
  showFireRoutes: boolean;
  showFireEquipment: boolean;
}
```

Key implementation details:
- Walls use `MeshPhysicalMaterial` with `opacity: 0.35` (0.08 in X-ray mode)
- Roofs use `MeshStandardMaterial` with `opacity: 0.6` (0.05 in X-ray)
- Edge wireframes use `<lineSegments>` with `EdgesGeometry`
- Fire route dots animate along paths using `useFrame`
- Room click uses `useThree` + raycaster on pointer events
- Camera: perspective 50 FOV, position `(25, 22, 25)`, lookAt origin
- Lighting: ambient (0x334155, 0.6), directional sun + fill light, shadows enabled

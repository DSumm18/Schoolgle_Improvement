# Website Scan → Ofsted Evidence Assessment

## What Can Be "Ticked Off" From a Website Scan

This document maps which Ofsted readiness evidence items can be satisfied (fully or partially) from a single website compliance scan, potentially saving schools significant preparation time.

---

## Summary

| Metric                                                | Value                                        |
| ----------------------------------------------------- | -------------------------------------------- |
| **Total Ofsted-mapped website requirements**          | 9 of 30                                      |
| **Ofsted categories with website evidence**           | 5 of 6                                       |
| **Estimated evidence items satisfiable from website** | 15-25 (of ~50 typical Ofsted evidence items) |
| **Estimated time saved**                              | 30-50% of initial evidence gathering         |
| **Cost per scan**                                     | ~$0.01 (AI) + ~3 minutes (crawl time)        |

## Ofsted Evidence Items Satisfied by Website Scan

### 1. Quality of Education (3 items from website)

| Website Requirement    | Ofsted Subcategory     | Evidence Provided                                                                | What Inspector Looks For                                                             | Confidence                       |
| ---------------------- | ---------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------- |
| **Curriculum Content** | `education-curriculum` | Subject-by-subject curriculum published per year group, curriculum intent/vision | Is there a broad and ambitious curriculum? Is curriculum intent clearly articulated? | HIGH - direct evidence           |
| **Phonics & Reading**  | `education-reading`    | Named phonics programme, reading approach, reading for pleasure strategy         | Is there a systematic approach to reading? Is the phonics programme DfE-validated?   | HIGH - direct evidence           |
| **KS2 Results**        | `education-outcomes`   | Performance data, comparison to national averages, progress measures             | Are outcomes in line with or above national? Is there a trend of improvement?        | MEDIUM - needs current year data |

**What this means**: An inspector arriving at a school can immediately see whether the curriculum is articulated online, whether reading is a priority, and what outcomes look like. The website scan captures exactly what they'd check first.

## What CANNOT Be Ticked Off From Website Alone

These Ofsted evidence items **require in-school evidence** (Google Drive documents, observations, interviews):

| Ofsted Area                 | Evidence Needed                 | Why Website Can't Provide              |
| --------------------------- | ------------------------------- | -------------------------------------- |
| **Lesson observations**     | Teaching quality evidence       | Requires classroom visits              |
| **Work scrutiny**           | Pupils' books, progression      | Physical/digital evidence from lessons |
| **Pupil voice**             | Pupil interviews, surveys       | Requires direct engagement             |
| **Staff interviews**        | Staff understanding of policies | Requires conversation                  |
| **Single Central Record**   | DBS checks, safer recruitment   | Confidential; never on website         |
| **Attendance data**         | Current attendance figures      | Internal data, not published           |
| **Exclusion data**          | Exclusion rates, patterns       | Internal data                          |
| **CPD records**             | Staff training evidence         | Internal records                       |
| **Self-evaluation**         | SEF document                    | Usually internal                       |
| **School Development Plan** | Improvement priorities          | Usually internal                       |
| **Governor minutes**        | Evidence of challenge           | Usually confidential                   |
| **Budget allocation**       | Detailed spending               | Internal financial data                |
| **Assessment data**         | Internal tracking data          | Beyond published KS2 results           |
| **Curriculum planning**     | Detailed schemes of work        | Website shows overview, not detail     |

### Evidence Auto-Linked to Ofsted Readiness

After a full scan with AI, the following happens automatically:

1. **9 requirements** with Ofsted mappings create entries in `documents` table with `provider: "website"`
2. **9 evidence_matches** link those documents to specific Ofsted categories/subcategories
3. The Ofsted readiness tracker can immediately show these as "website evidence" alongside Google Drive evidence
4. Each evidence item includes:
   - Direct link to the specific website page
   - Compliance score (0-100)
   - Quality score (1-5)
   - Evidence quotes extracted by AI
   - Gaps and recommendations for improvement

## Recommended Scan Workflow

1. **First Scan** (Day 1): Run full website scan → Get baseline compliance score
2. **Review Report**: Identify priority gaps and false negatives
3. **Fix Critical Gaps**: Update website with missing statutory content
4. **Re-scan** (Day 7): Verify improvements, get updated scores
5. **Connect Google Drive**: Scan Drive for in-school evidence that complements website evidence
6. **Combined View**: Ofsted readiness tracker shows both website + Drive evidence side by side
7. **Regular Re-scans**: Monthly automated scans to catch outdated content

## Integration with Ofsted Readiness Tracker

The website scan feeds directly into the existing Ofsted readiness system:

```
Website Scan → documents (provider: "website")
                    ↓
             evidence_matches (framework_type: "ofsted")
                    ↓
             Ofsted Readiness Tracker (combined with Drive evidence)
```

### What the User Sees

In the Ofsted Readiness dashboard:

- **Evidence count increases** by 9-15 items after first scan
- **Categories with evidence** jumps from Google Drive-only to Drive + Website
- **Compliance gaps** are highlighted with specific website page links
- **Recommendations** tell the school exactly what to add/update on their website

### Example: Quality of Education Category

Before website scan:

- 3 evidence items (from Google Drive: curriculum policy, SoW, assessment data)

After website scan:

- 6 evidence items (+3 from website: curriculum overview page, phonics page, KS2 results page)
- Each website item links directly to the page URL
- Quality score indicates how well the website communicates curriculum intent

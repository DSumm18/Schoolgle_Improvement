# Policy Domain Source Matrix

Last checked: 1 May 2026

This matrix is the starting point for Schoolgle policy domain packs. Each pack should separate:

1. official source expectations;
2. the school-local policy;
3. the school-local SOP or operating routine;
4. advisory findings and optional user-created tasks.

Schoolgle should branch checks by school type where duties differ, especially LA-maintained schools, academies, independent schools, voluntary-aided/foundation schools, faith schools and trust-level policy ownership.

## Current Review Flags

- RSHE: revised DfE guidance is expected for introduction on 1 September 2026; track transition readiness separately from current compliance.
- Medical conditions: do not replace existing statutory guidance until final DfE guidance is published.
- Safeguarding: treat the latest final KCSIE publication as enforceable; consultation drafts should be shown as future-readiness only.
- Equality: schools should seek current legal/HR advice on sex/gender, toilets/changing, uniform and RSHE wording where local policy is sensitive.
- Admissions, pay and HR: branch checks by school type, employer, trust funding agreement, diocesan/foundation status and LA scheme.

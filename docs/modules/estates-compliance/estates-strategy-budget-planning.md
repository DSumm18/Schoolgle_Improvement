# Estates Strategy & Budget Planning

**Transforming Day-to-Day Compliance into Long-Term Strategic Planning**

---

## Overview

Schools face a constant pressure on budgets. Compliance findings accumulate, but there's no systematic way to plan for upcoming expenditures. Items get forgotten until they become urgent, or schools spend money on non-statutory work that could wait.

**Schoolgle turns day-to-day compliance findings into a strategic estates plan.**

---

## The Problem

### Current Reality

```
January: Contractor report recommends replacing calorifier
  → SBM says "No budget this year"
  → Item forgotten

June: Boiler breakdown (emergency)
  → No planned replacement
  → Emergency repair costs 3x planned replacement
  → School closed for 2 days

September: Governors ask "What's coming up?"
  → SBM scrambles to find reports
  → Incomplete picture
  → Budget setting based on guesswork
```

### What's Missing

1. **No central record** of recommended works
2. **No prioritization** of statutory vs optional
3. **No budget forecasting** beyond the current year
4. **No condition tracking** linking to financial planning
5. **No visibility** for governors/trust boards

---

## Integration with Compliance Findings

### Automatic vs Manual Addition

| Finding Type | Auto-Add to Strategy? | Why |
|--------------|----------------------|-----|
| Statutory required with cost estimate | ✅ Yes (prompt) | Must be planned |
| Statutory required, no cost | ❌ No | Add when quote obtained |
| Good practice with cost | ❌ No | User decision |
| Contractor suggestion | ❌ No | Optional, user decision |

## Database Schema

### Budget Items Table

```sql
CREATE TABLE estates_budget_items (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  organization_id UUID NOT NULL REFERENCES organizations(id) ON DELETE CASCADE,

  -- Item details
  title TEXT NOT NULL,
  description TEXT,
  category TEXT NOT NULL CHECK (category IN (
    'replacement', 'upgrade', 'new_installation',
    'repair', 'inspection', 'testing', 'maintenance'
  )),

  -- Classification
  classification TEXT NOT NULL CHECK (classification IN (
    'statutory', 'good_practice', 'contractor_suggestion',
    'planned_maintenance', 'emergency'
  )),

  -- Source
  source_finding_id UUID REFERENCES estates_compliance_tasks(id),
  source_type TEXT CHECK (source_type IN (
    'contractor_report', 'inspection', 'monitoring',
    'condition_survey', 'manual_entry'
  )),
  source TEXT,
  source_url TEXT,

  -- Asset
  asset_id UUID REFERENCES estates_assets(id),
  asset_name TEXT,

  -- Financials
  estimated_cost NUMERIC(10,2),
  actual_cost NUMERIC(10,2),
  currency TEXT DEFAULT 'GBP',

  -- Estimates from multiple sources
  cost_estimates JSONB DEFAULT '[]'::jsonb,  -- [{source, amount, date}]

  -- Timing
  target_fiscal_year TEXT NOT NULL,  -- '2026/27'
  target_quarter TEXT CHECK (target_quarter IN ('Q1', 'Q2', 'Q3', 'Q4')),
  target_month INTEGER CHECK (target_month BETWEEN 1 AND 12),
  actual_completion_date DATE,

  -- Priority
  priority TEXT DEFAULT 'medium' CHECK (priority IN ('critical', 'high', 'medium', 'low')),

  -- Status
  status TEXT DEFAULT 'planned' CHECK (status IN (
    'planned', 'proposed', 'approved', 'in_progress',
    'completed', 'deferred', 'cancelled', 'on_hold'
  )),

  -- Deferment
  deferred_from TEXT,  -- Originally planned for this year
  deferment_reason TEXT,

  -- Execution
  assigned_contractor_id UUID REFERENCES estates_contractors(id),
  scheduled_start_date DATE,
  scheduled_end_date DATE,

  -- Approval
  approved_by UUID REFERENCES auth.users(id),
  approved_at TIMESTAMPTZ,
  approval_notes TEXT,

  -- Completion
  completed_by UUID REFERENCES auth.users(id),
  completed_at TIMESTAMPTZ,
  completion_notes TEXT,
  completion_photos TEXT[],

  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_budget_items_org ON estates_budget_items(organization_id);
CREATE INDEX idx_budget_items_year ON estates_budget_items(target_fiscal_year);
CREATE INDEX idx_budget_items_status ON estates_budget_items(status);
CREATE INDEX idx_budget_items_classification ON estates_budget_items(classification);
CREATE INDEX idx_budget_items_priority ON estates_budget_items(priority);
```

### Budget Summary View

```sql
-- Materialized view for quick dashboard access
CREATE MATERIALIZED VIEW estates_budget_summary AS
SELECT
  organization_id,
  target_fiscal_year,
  classification,
  COUNT(*) as item_count,
  SUM(estimated_cost) as total_estimated,
  SUM(actual_cost) as total_actual,
  COUNT(*) FILTER (WHERE status = 'completed') as completed_count,
  COUNT(*) FILTER (WHERE status = 'planned') as planned_count,
  COUNT(*) FILTER (WHERE status = 'approved') as approved_count
FROM estates_budget_items
WHERE status NOT IN ('cancelled')
GROUP BY organization_id, target_fiscal_year, classification;

CREATE UNIQUE INDEX budget_summary_idx
  ON estates_budget_summary(organization_id, target_fiscal_year, classification);
```

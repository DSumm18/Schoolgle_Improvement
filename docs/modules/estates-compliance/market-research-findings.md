## Mobile App Requirements (Critical Finding)

### What Users Are Telling Us

**iAM Compliant Users Explicitly Requesting Mobile App:**
- **James Brazier** (Site Co-ordinator): "App needed to make it more efficient and easier to use on mobile devices."
- **João moura** (Site Manager): Needs to record checks while walking around the building
- **Richard** (Caretaker): Works in the field, needs to know what tasks are due
- **Mark Baden** (Site Manager): "more in-depth knowledge is require, when uploading batch files" - mobile upload needed

### Why Mobile App Is Critical

1. **Site Staff Work in the Field**
   - Caretakers and site managers are rarely at desks
   - Need to record checks while walking the building
   - Fire alarm testing, water flushing, visual inspections all happen on-site

2. **Mobile-Responsive Is Not Enough**
   - iAM Compliant has mobile-responsive site
   - Users still requesting native app
   - Responsive sites don't work well offline
   - Can't access device hardware (camera, barcode scanner) properly

3. **Key Mobile Features Needed**

| Feature | Why It Matters | User Quote |
|---------|----------------|-------------|
| **Offline mode** | No Wi-Fi in basements, boiler rooms, outbuildings | "Takes a long while getting used to" (Richard) |
| **Quick task completion** | Field workers need fast, simple interface | "App needed to make it more efficient" (James) |
| **Photo upload** | Evidence of condition, damage, completed work | "no more bits of paper in files" (Greg) |
| **QR/barcode scanning** | Quick asset identification, check-in | "Fast and easy" (João) |
| **Voice input (Edwina)** | Hands-free operation, safety | "Helps keep on top of everything" (David) |
| **Push notifications** | Immediate task reminders | "weekly reminder" (Allison) |
| **GPS/time stamping** | Proof of presence, audit trail | "giving the auditor access" (Gemma) |

### Mobile App MVP Features

**Must-Have for Launch:**
1. ✅ View today's tasks
2. ✅ Complete tasks with one tap
3. ✅ Take photo evidence
4. ✅ Record temperature/values
5. ✅ Submit offline (syncs when online)
6. ✅ QR code scanning for assets
7. ✅ Push notifications for due tasks
8. ✅ Ed AI chat for guidance

**Nice-to-Have for Later:**
1. Voice input (Edwina)

## Summary of Key Findings

### What We Learned

**Critical User Pain Points:**
1. **Parago/Civica:** Severe login issues, poor support, expensive, schools leaving
2. **iAM Compliant:** No native mobile app, can't print/export for logbook, complicated workflows, learning curve

**What Users Love:**
1. **iAM Compliant:** Governor reporting, helpdesk, weekly reminders, sustainability reporting, audit access
2. **Every Compliance:** Comprehensive feature set, RAG dashboards, mobile apps

**Major Market Gaps (Our Opportunities):**
1. No expert guidance built in (Ed AI differentiator)
2. No contractor coordination system
3. No unified cross-module dashboard
4. No role-based authorization
5. No proactive problem prevention
6. Poor mobile experience (responsive not enough)

### What This Means for Schoolgle

**Must-Have for MVP:**
- Native mobile app with offline mode (CRITICAL)
- Print/export for logbook functionality
- Ed AI expert guidance throughout
- Unified helpdesk all staff can use
- Contractor coordination system
- Role-based authorization
- Governor reporting (one-click)

**Features That Will Win Users:**
- Expert validation (Am I qualified?)
- Proactive reminders (not reactive)
- Simplified workflows (tested with caretakers)
- Email-to-ticket for all staff
- Sustainability reporting

**What We're Doing Differently:**
- Ed AI as first-line support (always available)
- Expert guidance, not just tracking
- End-to-end contractor management
- Unified dashboard across ALL modules
- Mobile-first with voice (Edwina)

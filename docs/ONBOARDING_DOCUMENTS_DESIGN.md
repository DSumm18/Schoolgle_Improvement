### New Table: `onboarding_documents`

```sql
CREATE TABLE IF NOT EXISTS onboarding_documents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    lead_id UUID REFERENCES onboarding_leads(id) ON DELETE CASCADE,
    organization_id UUID REFERENCES organizations(id) ON DELETE CASCADE,

    -- Document details
    document_type TEXT NOT NULL,
    -- master_agreement, dpa, dpia, privacy_notice, cookie_policy, sla,
    -- staff_list, class_list, logo, colours, census_xml, website_url,
    -- consent_drive, safeguarding_lead, finance_contact
    -- welcome_guide, user_quickstart, module_guide, incident_procedure

    category TEXT NOT NULL,
    -- 'legal_signed', 'legal_provided', 'school_setup', 'tech_setup',
    -- 'provision_generated', 'provision_signed'

    -- File storage
    file_name TEXT,
    file_url TEXT,
    file_size INTEGER,
    file_type TEXT,  -- pdf, docx, png, csv, etc.
    storage_provider TEXT DEFAULT 'schoolgle_drive',  -- schoolgle_drive, school_drive, gcs, s3

    -- Status
    status TEXT DEFAULT 'pending' CHECK (status IN (
        'pending',           -- Awaiting upload/signature
        'awaiting_review',   -- Uploaded, needs review
        'approved',          // Approved
        'rejected',          // Rejected with reason
        'signed',            // Signed by school
        'generated',         // Generated by Schoolgle
        'expired'            // Expired/ superseded
    )),

    -- Ownership
    required_from TEXT CHECK (required_from IN ('school', 'schoolgle', 'either')),
    provided_by TEXT CHECK (provided_by IN ('school', 'schoolgle', 'auto')),

    -- Template (if applicable)
    template_id TEXT,
    template_version TEXT,

    -- Signing (for legal documents)
    signed_by TEXT,
    signed_at TIMESTAMPTZ,
    signature_ip TEXT,
    signature_method TEXT,  -- electronic, wet_ink, digital

    -- Expiry (for documents that expire)
    expires_at TIMESTAMPTZ,
    reminder_sent BOOLEAN DEFAULT false,

    -- Review tracking
    reviewed_by UUID,
    reviewed_at TIMESTAMPTZ,
    review_notes TEXT,

    -- Version tracking
    version INTEGER DEFAULT 1,
    supersedes_document_id UUID REFERENCES onboarding_documents(id),

    -- Metadata
    description TEXT,
    tags TEXT[] DEFAULT ARRAY[],
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),

    UNIQUE(lead_id, document_type, version)
);
CREATE INDEX idx_onboarding_docs_lead ON onboarding_documents(lead_id);
CREATE INDEX idx_onboarding_docs_org ON onboarding_documents(organization_id);
CREATE INDEX idx_onboarding_docs_status ON onboarding_documents(status);
```

### New Table: `document_templates`

```sql
CREATE TABLE IF NOT EXISTS document_templates (

    -- Legal backing

    approved_by_legal BOOLEAN DEFAULT FALSE,
    approved_at TIMESTAMPTZ,

    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 3. DUAL-SIDED CHECKLISTS

### Table: `onboarding_checklists`

```sql
CREATE TABLE IF NOT EXISTS onboarding_checklists (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    lead_id UUID REFERENCES onboarding_leads(id) ON DELETE CASCADE,
    organization_id UUID REFERENCES organizations(id) ON DELETE CASCADE,

    checklist_type TEXT NOT NULL,
    -- 'schoolgle_required', 'school_required', 'schoolgle_optional', 'school_optional'

    category TEXT NOT NULL,
    -- 'legal', 'technical', 'branding', 'data', 'training'

    title TEXT NOT NULL,
    description TEXT,

    -- Items within this checklist
    items JSONB DEFAULT '[]',
    -- [{
    --   id: "staff_list",
    --   title: "Staff list CSV uploaded",
    --   status: "pending",  // pending, in_progress, complete, skipped, blocked
    --   required: true,
    --   assigned_to: "school",  // school, schoolgle
    --   due_by: "trial_start",
    --   evidence_url: null,
    --   notes: null,
    --   completed_at: null,
    --   completed_by: null
    -- }]

    -- Overall progress
    total_items INTEGER DEFAULT 0,
    completed_items INTEGER DEFAULT 0,

    -- Status
    status TEXT DEFAULT 'not_started' CHECK (status IN (
        'not_started', 'in_progress', 'awaiting_input', 'complete', 'blocked'
    )),

    -- Dependencies
    depends_on CHECKLIST UUID[] DEFAULT '{}',
    blocks_onboarding BOOLEAN DEFAULT FALSE,

    -- Timeline
    due_by TIMESTAMPTZ,
    started_at TIMESTAMPTZ,
    completed_at TIMESTAMPTZ,

    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### Contract Types

| Contract Type | When Used | Key Clauses |
|---------------|-----------|-------------|
| **Trial Agreement** | Free trial | Limited liability, 14/30 days, no payment |
| **Core Agreement** | Core/Pro plans | Standard terms, annual payment, module list |
| **Enterprise Schedule** | Enterprise plans | Custom pricing, SLA, support hours, cancellation |
| **DPA** | All (legal req) | Data processor role, data subject rights, breach notification |
| **Module Addendum** | Additional modules | Per-module pricing, scope, support |

## 6. API ENDPOINTS

### Documents
```
GET   /api/admin/documents                    - List all documents
GET    /api/admin/documents?leadId={id}        - Documents for a lead
POST   /api/admin/documents                    - Upload document
PATCH  /api/admin/documents/{id}                - Update status
DELETE /api/admin/documents/{id}                - Delete document
GET    /api/admin/documents/{id}/download       - Download document
```

### Checklists
```
GET    /api/admin/checklists                   - List all checklists
GET    /api/admin/checklists?leadId={id}        - Checklists for a lead
POST   /api/admin/checklists                   - Create from template
PATCH  /api/admin/checklists/{id}              - Update checklist/item
PATCH  /api/admin/checklists/{id}/items/{itemId} - Update item status
```

### Contracts
```
POST   /api/admin/contracts/generate          - Generate contract from template
GET    /api/admin/contracts/{id}/preview        - Preview contract
POST   /api/admin/contracts/{id}/send           - Send for signature
GET    /api/admin/contracts/{id}/download       - Download signed PDF
```

## 8. DOCUMENT TEMPLATES

### Master Services Agreement Sections

1. **Parties** - Schoolgle Limited vs School
2. **Services** - Module descriptions, access levels
3. **Fees & Payment** - Pricing, payment terms, late fees
4. **Term** - Start date, duration, auto-renewal
5. **Data Protection** - GDPR compliance, data processing
6. **Acceptable Use** - Fair use, no resale, no reverse engineering
7. **Limitation of Liability** - Caps, exclusions
8. **Termination** - Notice periods, effect of termination
9. **Governing Law** - Jurisdiction (England & Wales)
10. **Schedules** - Module descriptions, SLAs, Subprocessor list

### DPA Sections

1. **Data Controller & Processor Roles**
2. **Data Types Processed** (pupil names, assessments, etc.)
3. **Lawful Basis for Processing**
4. **Data Subject Rights**
5. **Security Measures**
6. **Subprocessors** (Supabase, Vercel, OpenRouter, etc.)
7. **Data Breach Notification**
8. **International Data Transfers**
9. **Data Retention**
10. **Audit Rights**

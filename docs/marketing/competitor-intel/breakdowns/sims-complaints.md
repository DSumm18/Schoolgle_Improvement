# SIMS User Complaints — 15 Real Pain Points from Forums, Reviews & Media

**Last updated:** 2026-03-23
**Sources:** EduGeek forums, Capterra reviews, App Store reviews, Schools Week, WhichMIS, TeacherToolkit, CMA investigation

---

## The Headline Numbers

- **3,000+ schools left in one year** — 6x the previous rate
- Market share dropped from **84% (2012) to ~50% (2025)**
- SIMS 8 was a **£36m write-off** — "significant issues with technological feasibility"
- **397 schools joined collective legal action** via Stone King
- Bromcom alleged **£75.4m in overcharging** over a decade
- Even SCOMIS (40+ year SIMS partner) switched to Arbor

---

## 1. Catastrophically Slow Performance

- **Problem**: Even on dedicated servers with 64GB RAM and RAID 10 SSDs, SIMS is slow. Login takes up to 10 minutes. Reports grew from 7 to 40 minutes
- **Who**: IT managers, school admins, teachers
- **Tone**: Resigned — "regardless of how quick your server, SIMS is slow, period"
- **Schoolgle angle**: Cloud-native, no on-prem SQL databases, instant page loads
- **Sources**: [EduGeek](https://www.edugeek.net/forums/mis-systems/225844-sims-slow-performance.html)

## 2. Constant Crashes and Downtime

- **Problem**: Random crashes with no error messages. Hosted SIMS goes down entirely. SIMS Connected migration caused widespread outages
- **Who**: IT managers, teachers, office staff
- **Tone**: Anger and helplessness
- **Schoolgle angle**: Modern cloud SaaS, no SQL database corruption
- **Sources**: [EduGeek](https://www.edugeek.net/forums/topic/224977-sims-crashes/)

## 3. Broken, Unreliable Reports

- **Problem**: Pupils appear twice or not at all, marksheet data fails to populate, report steps must be repeated. Data can't be trusted
- **Who**: Deputy heads, data managers, SBMs
- **Tone**: Anxiety and distrust
- **Schoolgle angle**: Intelligence Engine provides AI-powered, cross-referenced analysis from clean cloud data
- **Sources**: [Capterra](https://www.capterra.com/p/134929/SIMS/reviews/)

## 4. Appalling Customer Support

- **Problem**: Support takes months. First-line "don't know the answer to anything." Users directed to read 800 pages of docs. "Not our problem" responses
- **Who**: IT managers, SBMs, data managers
- **Tone**: Exasperation — support is a dead end
- **Schoolgle angle**: Ed AI provides instant 24/7 expert help across all domains. No tickets, no waiting
- **Sources**: [EduGeek](https://www.edugeek.net/forums/topic/173277-capita-sims-support-shockingly-bad/)

## 5. Hostile Vendor Lock-In

- **Problem**: ESS told schools sharing databases with competitors would breach contracts. Data migration made "complex, time-consuming and error prone." Contracts forcibly extended 1→3 years. CMA investigated
- **Who**: SBMs, headteachers, MAT leaders
- **Tone**: Outrage — "aggressive tactics" per ISBL chief exec
- **Schoolgle angle**: No lock-in. Schools own their data. Open architecture. No punitive contracts
- **Sources**: [Schools Week](https://schoolsweek.co.uk/sims-seeks-to-stem-exodus-of-schools/), [TES](https://www.tes.com/magazine/news/general/hundreds-schools-join-legal-action-over-sims-contract)

## 6. Failed Modernisation (SIMS 8 / Next Gen)

- **Problem**: SIMS 8 written off at £36m. Next Gen described as "very hard to use." Cloud transition is "a slow-motion car crash" with "fragmented system that feels even more frustrating than before"
- **Who**: IT managers, SBMs, headteachers
- **Tone**: Betrayal — promised modern system, got worse
- **Schoolgle angle**: Built cloud-native from day one with Next.js 16. No legacy migration
- **Sources**: [Involve Education](https://involveeducation.com/blog/which-mis-is-the-best)

## 7. Unusable Mobile Apps

- **Problem**: Teacher app crashes every morning, requires full login each time (remember-me broken). Parent app loops "session expired" errors. "One of the most frustrating app experiences"
- **Who**: Teachers, parents
- **Tone**: Contempt — "if they're paying for this, they should ask for a refund"
- **Schoolgle angle**: Responsive web app on any device, no app store needed. Ed website chat for parents
- **Sources**: [Apple App Store](https://apps.apple.com/gb/app/sims-teacher/id875278561), [Google Play](https://play.google.com/store/apps/details?id=uk.co.capita.sims.mobile.parentapp&hl=en_GB)

## 8. Extortionate Pricing with Bolt-Ons

- **Problem**: Core SIMS expensive, then every feature is an additional bolt-on. InTouch costs double comparable systems. Training costs extra. Charges increased threefold since 1999
- **Who**: SBMs, headteachers, MAT finance leads
- **Tone**: Resentment — feeling exploited by monopoly pricing
- **Schoolgle angle**: Everything bundled in one subscription. No bolt-ons. The "11p/hour" Ed AI pitch
- **Sources**: [TeacherToolkit](https://www.teachertoolkit.co.uk/2016/01/17/time-to-move-over/)

## 9. Doesn't Serve MATs

- **Problem**: "From a MAT point of view, SIMS doesn't deliver." Schools run separate instances. No trust-wide visibility. Can't navigate in a single web browser across schools
- **Who**: MAT leaders, trust CEOs, CFOs
- **Tone**: Pragmatic frustration — forced to leave for operational reasons
- **Schoolgle angle**: Organisation-based architecture supports multi-school trusts natively. Cross-school intelligence
- **Sources**: [SCOMIS](https://www.scomis.org/scomislive-2022/moving-your-mis-to-arbor-cornerstone-academy-trust/)

## 10. Missing Core Functionality

- **Problem**: Schools must buy third-party tools for features that should be built in. Teaching and learning "at best had bolt-on modules that half-heartedly approached it"
- **Who**: Headteachers, SBMs, IT managers
- **Tone**: Weariness — constantly patching gaps
- **Schoolgle angle**: 11+ integrated modules. No third-party dependencies
- **Sources**: [EduGeek](https://www.edugeek.net/forums/mis-systems/200298-sims-alternatives-4.html)

## 11. Census Nightmares

- **Problem**: Updates break census functionality. DfE validation errors require late patches. Summer 2025 had "loads of failed installs." Breaking changes to attendance codes
- **Who**: Data managers, SBMs, IT managers
- **Tone**: Stress and panic — census deadlines are immovable
- **Schoolgle angle**: DfE Data Integration pulls directly from GIAS and DfE data warehouse. Validated pipelines, not fragile SQL queries
- **Sources**: [EduGeek](https://www.edugeek.net/forums/topic/224033-sims-summer-2025-loads-of-failed-installed/)

## 12. Outdated, Ugly Interface

- **Problem**: "Clunky and expensive," "dull as dishwater," "not designed for the end user." Designed in the 1980s and it shows
- **Who**: Teachers, heads, everyone

## 13. Supply Teacher Login Chaos

- **Problem**: No support for multiple teachers per class for registers. Schools share login credentials with supply teachers — security and safeguarding risk
- **Who**: Teachers, IT managers
- **Tone**: Concern about security

## 14. Terrifying to Make Changes

- **Problem**: "If you make mistakes, you need to do a lot of works to remove it." Creating templates is "not user friendly at all and one mistake will be disaster"

## Using These Complaints in Sales

### The "SIMS School" Conversation

When you're talking to a SIMS school, you don't need to trash-talk SIMS. Just ask these questions:

1. "How long does it take to run a report in SIMS?" (They'll wince)
2. "When's the last time you called SIMS support and got a useful answer?" (They'll laugh)
3. "If Ofsted called tomorrow, how quickly could you pull together your evidence?" (They'll go quiet)
4. "How many separate systems are you paying for on top of SIMS?" (They'll start counting)

Then: "Schoolgle does all of that — the improvement, compliance, intelligence, and AI support — for £1,995/year. And it works alongside SIMS, so you don't have to switch MIS."

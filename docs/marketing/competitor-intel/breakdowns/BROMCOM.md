## 4. Product Suite

### Core MIS Modules
| Module | Description |
|--------|-------------|
| **Assessment** | Summative + formative, custom templates, Excel import/export, Primary Tracker wizard |
| **Attendance** | Daily registers, bulk updates, watchlists, automated letters, mobile registration |
| **Behaviour** | Event recording, monitoring, automated outcomes, positive/negative tracking |
| **Timetabling** | Built-in (only cloud MIS with integrated timetabling), two-way sync with MIS |
| **Reporting** | Built-in reports + ad-hoc report writer, analytics dashboards |
| **Communication** | Staff/Parent/Pupil messaging, automated + manual, push notifications |
| **Census** | Automated DfE census returns |
| **Examinations** | Exam management and results |
| **SEND** | SEND register, provision mapping, EHCP tracking |
| **Safeguarding** | Safeguarding module (details limited) |
| **Cover** | Staff cover management |
| **Curriculum** | Curriculum planning |
| **Clubs** | Clubs and trips management |
| **Dinner** | Meal management |
| **Options** | Student options choices |

### Bromcom Finance
- Fully integrated cloud-based accounting system
- Budget planning, HR integration, payroll data access
- Unique selling point: MIS + Finance in one platform
- MAT Finance with 50% discount for One-Stop-Shop customers

### Bromcom Vision (MAT Dashboard)
- Central data hub for multi-academy trusts
- Real-time data aggregation from all trust schools
- Custom dashboards with Power BI integration
- Trust-wide analytics: attendance, assessment, behaviour, demographics
- Central policy deployment and settings cascade
- Staff/student/group management from single location
- Cross-MIS compatibility (can pull data from non-Bromcom schools)
- Free for One-Stop-Shop customers with 20+ schools

### MyChildAtSchool (MCAS) Parent App
- Free on iOS and Android
- Real-time attendance, behaviour, assessment data
- Homework tracking
- Parents' evening booking (no third-party needed)
- Push notifications and messaging
- Dinner money and online payments
- Parental consents management
- Data update requests
- Multi-school, multi-student support
- Welsh language support
- Biometric authentication, magic link login

### Bromcom Student App
- Student-facing app (poorly reviewed on app stores)
- Timetable, homework, behaviour points access

### Bromcom AI
- **Launched**: 2023 (phased rollout)
- **Technology**: Own language model based on GPT architecture + Azure OpenAI integration
- **Key capabilities**:
  - Natural language data queries ("show me Year 7 PP attendance")
  - Predictive analytics for student outcomes
  - Content generation (letters, lesson plans, quizzes, homework)
  - Multi-language translation (including parent communications)
  - Voice input support
  - Chat history in Quick Reports
  - Workflow-embedded AI (auto-generates outputs during processes)
- **Security**: Data stays within school's own database; UK-only Azure hosting; no data used for model training
- **Included**: Two tiers of AI included in annual service charge with baseline AI tokens
- **Phase 4 (upcoming)**: AI embedded at key workflow points

## 5. Pricing Model

### Structure
- **Per-pupil pricing** varying by school type (primary/secondary) and package tier
- **Three tiers**: Standard MIS, Plus MIS, One-Stop-Shop MIS (MIS + Finance)

### Discounts
- Single service reduction: -GBP 1/pupil (primary), -GBP 1.50/pupil (secondary)
- Support Partner discount: 20% off base + per-pupil cost
- Multi-school discount for 20+ schools
- MAT Finance: 50% off if all schools on One-Stop-Shop
- Buy-Back scheme: discount based on remaining contract with existing supplier

### What's Included
- Hosting, annual licence, support/help desk, maintenance, data backup
- Two tiers of Bromcom AI with baseline tokens
- MCAS parent app (free)
- Data migration service from SIMS, Arbor, RM Integris (direct extraction)

### Procurement
- Available via **G-Cloud Digital Marketplace**
- Contracts up to 4 years
- TCO Calculator available at bromcom.com/tco

### Benchmark Pricing
- Average cost reduced to **GBP 6.36/pupil/year** in one LA procurement (down from GBP 32)
- This is significantly cheaper than SIMS historically

## 11. Weaknesses & Opportunities for Schoolgle

### Bromcom Weaknesses
1. **No school improvement focus** - Bromcom is purely MIS/admin; no Ofsted readiness, SEF, evidence mapping
2. **No AI for school improvement** - Their AI is data query/content generation, not improvement analysis
3. **Poor parent/student app UX** - Consistently criticised
4. **Performance concerns** - Scalability questions as user base grows
5. **No EEF integration** - No research-backed strategy recommendations
6. **No compliance module** - No estates compliance, statutory compliance tracking
7. **No governance portal** - No board management, governor training tracking
8. **No document intelligence** - No cloud storage scanning, evidence extraction
9. **Limited to MIS data** - Cannot cross-reference with external data sources for insights
10. **No pseudonymised pupil analysis** - No privacy-first assessment gap analysis

### Schoolgle Opportunities
1. **Complement, don't compete**: Position Schoolgle as the improvement layer ON TOP of Bromcom (or any MIS)
2. **Integration pitch**: "Bromcom manages your data, Schoolgle improves your school"
3. **AI differentiation**: Schoolgle's AI does improvement analysis; Bromcom's AI does data queries
4. **Target Bromcom schools**: 5,600+ schools already on a modern cloud platform, likely tech-forward
5. **SEND gap**: Bromcom has basic SEND; Schoolgle's planned SEND Hub is far more comprehensive
6. **Intelligence superiority**: School Intelligence Engine crosses module boundaries in ways Bromcom cannot
7. **Ofsted readiness**: Bromcom has zero Ofsted preparation tools
8. **Staff connectors**: Bromcom has HR data but no responsibility engine or compliance tracking

## 12. Competitive Landscape Context

The UK MIS market is in massive flux:
- SIMS declining rapidly (85% to 31% share)
- Arbor dominant and growing (44% England)
- Bromcom strong #3 (15-18% and growing)
- SIMS Next Gen rollout delayed until end 2026
- Integris/ScholarPack being migrated to Arbor by Feb 2026
- Schools increasingly expect cloud-first, integrated platforms

**Key insight**: As schools switch MIS providers (thousands per year), there's a window where they're also evaluating their entire EdTech stack. This is prime time to pitch Schoolgle as the improvement complement.

# Module: Survey Builder

## One-Line Value
"Parent voice, pupil voice, staff wellbeing — collected, analysed, and linked to school improvement."

## The Problem
- Schools need stakeholder voice for Ofsted but surveys are ad-hoc
- Google Forms works but results aren't linked to anything
- No AI analysis of free-text responses
- Parent response rates are low
- Results aren't systematically used for improvement planning

## What It Does
- **Survey Builder**: Drag-and-drop survey creation with multiple question types
- **Templates**: Pre-built surveys for parent, pupil, and staff voice
- **Distribution**: Email, link, and QR code distribution
- **AI Analysis**: Automatic sentiment analysis of free-text responses
- **Response Dashboard**: Real-time response tracking and visualisation
- **Evidence Linking**: Survey results connect to Ofsted framework areas

## Key Benefits
1. **Ofsted evidence** — stakeholder voice is a key inspection area
2. **AI insights** — automatic theme detection in free-text responses
3. **Easy distribution** — multiple channels to maximise response rates
4. **Connected** — results feed into school improvement actions
5. **Professional** — branded surveys that look good on mobile

## Value to School (Annual)
- Replaces: Google Forms + manual analysis + SurveyMonkey subscription
- Standalone worth: **£200-400/year**

## Demo Script (2 Minutes)
1. **Hook** (30s): "Ofsted asks about parent and pupil voice. What would you show them?"
2. **Quick build** (60s): Show creating a parent survey from template in 3 clicks, distribute via QR code
3. **Close** (30s): "Stakeholder voice, collected and analysed — evidence for every inspection."

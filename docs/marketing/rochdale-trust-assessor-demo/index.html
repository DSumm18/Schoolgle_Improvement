Live app: Rochdale Council Schools dashboard.

Pause on the sidebar before opening the module.

Pause Point 2

Explain the product model before the data.

Parent layer

Rochdale Council can have oversight across its connected schools.

School layer

Each school keeps its own data, evidence and module access.

Module layer

School Improvement Assessor is one school improvement app inside the wider platform.

Do not position this as Rochdale imposing a system. Position it as helping identify the right schools for a useful pilot.

Pause Point 3

Open School Improvement, then School Improvement Assessor.

Say

“This is where the LA school improvement work lives. Today I’m focusing on the Assessor because it is the strongest thing to show.”

If they ask about Ofsted Readiness, say it is the workflow this intelligence can feed, but today you are demonstrating the data engine first.

Headline order: understand where schools are first, then turn findings into Ofsted Readiness evidence, SEF content and improvement-plan actions.

Navigation moment: School Improvement module opened.

Rochdale view: useful to explain setup and missing connected data.

Pause Point 4

This screen shows the challenge as well as the product.

Challenge

Schools and LAs have data, but it sits in different places and formats.

Product value

The app shows what is connected, what is missing and what richer analysis can unlock.

Honest line

“Rochdale’s live setup is the workspace; PAYMAT gives us the populated example.”

Be explicit: Rochdale is already set up; PAYMAT is just the populated example so they can see the product with data in it.

Pause Point 5

Now explain where the data comes from.

1. Public DfE data KS2, attendance, persistent absence, census context, school identity and comparators.
2. School or trust captures Current in-year assessment snapshots, spreadsheets and school-submitted summaries.
3. Pupil-level evidence MIS/CTF data where supplied, pseudonymised for cohort and group analysis.

“The important bit is that Schoolgle labels the source, date and scope. It should never blend those layers silently.”

The differentiator is source-labelled intelligence: public DfE data, school captures and pupil evidence are kept separate and explained.

Pause Point 6

Use PAYMAT as the populated data example.

Say

“I’m switching to Pennine Academies Yorkshire here because it has demo-ready data, so you can see what Rochdale would get once schools connect their captures.”

This is not a dodge. It is clearer: Rochdale shows the LA workspace; PAYMAT shows the populated assessor engine.

Say this confidently. It is better to be transparent than pretend Rochdale already has full pilot data loaded.

Populated example: School Improvement Assessor with data captures and findings.

The data strip is where you explain source and freshness.

Pause Point 7

Talk through the source strip slowly.

Spreadsheet

Mid-year submission: school or trust-provided current assessment data.

DfE loaded

External public baseline for comparison, not current-year teacher assessment.

School summary

Additional school-level capture can add richer current context.

Pupil data

Unlocked only when MIS/CTF pupil-level evidence is connected.

Pause here: this is where Becky will understand the value — freshness, source and data quality all in one place.

Pause Point 8

This is what makes it different.

Say

“It does not just draw charts. It turns the data into questions leaders can actually use in a school improvement conversation.”

Mention: strongest school, needs-attention school, zero-GD writing flags and below-threshold combined outcomes. These are prompts for professional discussion, not accusations.

Keep saying "prompts for professional discussion". It protects the tone and reassures the LA this is not automated judgement.

Key findings: triage signals, not inspection judgements.

Pause Point 9

Answer the AI question without overclaiming.

Numbers first The core School Improvement Assessor calculations are deterministic and source-labelled: no hidden AI judgement.
AI where useful AI helps with narrative, evidence analysis, document checks and drafting questions/actions.
Approved providers Schoolgle policy allows only OpenAI, Anthropic, Google, Microsoft, Meta Llama and Mistral for school data.

“AI supports the professional judgement. It does not replace the adviser, headteacher or teacher.”

Approved AI providers only. The numbers are deterministic; AI helps with narrative, evidence checks and suggested questions/actions.

Pause Point 10

Be open about the challenges. That builds trust.

Different counts DfE census roll, school captures and pupil evidence can all have different scopes.
Freshness Published data is historic; school captures are current but self-reported.
Data quality Missing, inconsistent or over-optimistic values should become questions, not hidden assumptions.
Permissions Pupil-level depth only appears when schools connect the right evidence safely.

This honesty is a selling point: the app is designed to make uncertainty visible rather than pretend it is not there.

If data differs, we explain the lineage rather than forcing numbers to match. That is a quality feature.

# School Improvement Assessor Tightening Task

Date: 2026-05-21
Status: ready for implementation planning
Owner: Schoolgle Improvement project

## Goal

Make School Improvement Assessor the flagship sales wedge for Schoolgle, with a clear demo journey that a school improvement, trust, or local authority audience can understand in under three minutes.

## Product Spine

Use this sequence:

1. School Improvement Assessor: trust/LA overview, DfE context, school-submitted capture, trustee/school improvement questions.
2. School drill-down: one school with source-labelled evidence and cohort questions.
3. Assessment Intelligence: teacher-approved assessment evidence and evidence passports.
4. Ofsted Readiness: source-labelled findings become evidence checks, actions, owners, and audit trail.

## Rules

- Do not add demo-only UI.
- Do not add bespoke school-specific panels, colours, layouts, or hard-coded values.
- Use existing product components and proper data/import paths.
- Demo or illustrative data is allowed only through the normal capture/import structure and must be clearly labelled.
- Every metric must show source, date, scope, and calculation where relevant.
- If counts differ, explain source/scope differences rather than forcing them to match.

## Tightening Work

1. Rewrite page-level copy so it describes the product promise, not just the upload mechanics.
   - Current weak example: "Upload mid-year data. Cross-reference with DfE. No AI - pure numbers."
   - Direction: "Turn school, trust and pupil-level evidence into clear improvement questions, source-labelled findings and inspection-ready action."

2. Create a guided demo path with visible waypoints:
   - Trust overview.
   - School needing attention.
   - School strength worth sharing.
   - Pupil/cohort evidence where available.
   - Ofsted Readiness bridge.

3. Reduce sales-demo noise:
   - Hide or de-emphasise unrelated sidebar items for demo users if a permissions/sales navigation layer already exists.
   - Keep the internal registry intact.

4. Capture marketing-ready screenshots:
   - Trust/LA overview.
   - Trustee briefing / key findings.
   - School drill-down.
   - Assessment Intelligence teacher-approved flow.
   - Ofsted Readiness inspection intelligence.

5. Create one demo script:
   - 3-minute version for LinkedIn/demo login.
   - 10-minute version for LA/trust call.
   - One sentence explaining what the product is not.

## Success Test

A headteacher, MAT leader, or LA school improvement officer should be able to answer:

- What problem does this solve?
- What data is it using?
- Why should I trust the numbers?
- What action does it help me take?
- How could I try it with low risk?

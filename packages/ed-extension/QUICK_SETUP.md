# Quick Setup - No Console Needed! 🎉

## Why Browser TTS Works But Fish Audio Doesn't

**Browser TTS** = Built into Chrome (free, no API key needed) ✅  
**Fish Audio** = External service (needs API key) ❌

The extension **can't read your `.env.local` file** - they're separate apps!

## Easy Setup (2 Steps)

### Step 1: Click the Extension Icon
- Click the Ed extension icon in your browser toolbar
- A popup window will open

### Step 2: Paste Your Keys
1. **OpenRouter API Key**: Paste your OpenRouter API key from your password manager or environment store.
2. **Fish Audio API Key**: Paste your Fish Audio API key from your password manager or environment store.
3. **Edwina Voice ID**: Paste the configured Edwina voice ID.
4. Click **"💾 Save Configuration"**

### Step 3: Reload Any Page
- Visit any website (e.g., `educationendowmentfoundation.org.uk`)
- Press `F5` to reload
- Ed should now use **Edwina voice with Fish Audio**! 🎤

## That's It!

No console needed - just use the popup UI. The keys are saved in the extension and will persist across browser restarts.

# Design System: Schoolgle Landing Page

## 1. Visual Theme & Atmosphere
The Schoolgle landing page features a "Dark Mode Cosmic" aesthetic. It is airy yet focused, using deep midnight backgrounds with subtle vibrant accents and glassmorphism to create a sense of modern, premium software. The mood is professional, secure, and innovative.

## 2. Color Palette & Roles
- **Midnight Space (#0a0a12):** Primary background color for the landing page.
- **Deep Slate (#111118):** Secondary background used for section differentiation.
- **Primary Blue (#3b82f6):** Main accent color used for buttons, links, and highlights.
- **Amber Glow (#f59e0b):** Secondary accent color for specific calls to action or warnings.
- **Off-White (#f8fafc):** Primary text color for high readability.
- **Muted Slate (#94a3b8):** Secondary text color for supporting information.
- **Deep Steel (#64748b):** Muted text for tertiary information.

## 3. Typography Rules
- **Display Font (Outfit):** Used for all headings (H1-H6). Features tight letter-spacing (-0.02em) for a modern look.
- **Sans Font (Inter):** Used for all body copy and UI elements. Optimized for legibility and clarity.

## 4. Component Stylings
* **Buttons:** Primary buttons use a solid Primary Blue background. Secondary buttons use a glass-panel effect with a subtle border.
* **Cards/Containers:** Use a "Glass-Card" style: `rgba(17, 17, 24, 0.8)` background with a `12px` blur and a thin `rgba(59, 130, 246, 0.15)` border. Corners are generously rounded (`radius-2xl`).
* **Inputs/Forms:** Dark backgrounds with subtle borders that glow on focus.

## 5. Layout Principles
- **Whitespace:** Generous spacing between sections to avoid clutter.
- **Alignment:** Centralized focus for the Hero section, transition into grid-based layouts for features.
- **Accents:** Use of animated mesh gradients and radial glows to create depth.

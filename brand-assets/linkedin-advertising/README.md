# Schoolgle LinkedIn Advertising Assets

Reusable LinkedIn assets for profile, company page, and launch/update posts.

## Files

- `linkedin-advertising-profile-banner.png` — personal profile background image.
- `linkedin-advertising-company-banner.png` — Schoolgle company page cover image.
- `linkedin-advertising-post-image.png` — reusable post image for announcements.

## Placement

- Use `linkedin-advertising-profile-banner.png` on David's personal LinkedIn profile.
- Use `linkedin-advertising-company-banner.png` on the Schoolgle company page.
- Use `linkedin-advertising-post-image.png` for feed posts, product updates, and launch notes.

## LinkedIn Profile Banner Notes

- LinkedIn recommends `1584 x 396 px`, PNG or JPG, under 8MB.
- The profile photo overlaps the lower-left of the banner, so the profile banner keeps that area quiet.
- Keep important text and the logo towards the centre/right so it survives responsive cropping.

## Regenerate

From the repo root:

```powershell
python .\brand-assets\linkedin-advertising\generate-linkedin-assets.py
```

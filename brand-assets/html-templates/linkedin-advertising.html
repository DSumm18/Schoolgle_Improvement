How to use these in LinkedIn

Click a card to preview it, use Download PNG when LinkedIn needs an upload, or use Copy file path so you can paste/search the exact file name in a file picker. Drag-and-drop from a browser into LinkedIn is hit-and-miss, so the download/copy route is the reliable one.

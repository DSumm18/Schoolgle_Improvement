# School Performance Data Link

## Legislation

- School Information (England) Regulations 2008, Schedule 4
- Academy Trust Handbook 2025, Section 2.5 (for academies)

## Current References

Must link to the DfE School and College Performance service
(formerly known as Compare School Performance or School Performance
Tables). The current URL is https://www.find-school-performance-data.service.gov.uk/.
Links to the old domain (compare-school-performance.service.gov.uk)
may still redirect but should ideally be updated.

## Review Frequency

Link should be checked annually, particularly after the DfE publishes
new performance data (typically January each year). No formal review
cycle — the obligation is to maintain a working link.

## Required Content

1. A clearly labelled, working hyperlink to the school's page on the
   DfE School and College Performance service
2. The link must be findable — typically on a results, performance,
   or statutory information page
3. The link must resolve to the correct DfE service (ideally direct
   to the school's own performance page)

## Quality Indicators

- Link goes directly to the school's own page on the service (not
  just the homepage)
- Clearly labelled (e.g. "School Performance Data" or "Compare Our
  School Performance")
- Brief explanation of what the data shows
- Accompanied by the school's own commentary on its results
- Link opens in a new tab
- Context provided for any anomalous data years (e.g. COVID-19
  impact on 2020-2022 data)

## Red Flags

- No link to school performance data anywhere on the website
- Link is broken or returns a 404 error
- Link goes to a generic DfE page rather than the performance service
- Link goes to an outdated or decommissioned service
- School publishes its own performance data but does not link to the
  official DfE service

## Rating Descriptors

### Compliant (80-100)

- Working link to the DfE School and College Performance service is
  published on the school website
- Link is clearly labelled and easy to find
- Link resolves correctly, ideally to the school's own page

### Partial (40-79)

- Link exists but:
  - Is broken or redirects via the old domain
  - Goes to the service homepage rather than the school's own page
  - Is buried in a PDF rather than on a webpage
  - Is poorly labelled or hard to find

### Not Found / Non-Compliant (0-39)

- No link to school performance data found on the website
- Only a textual mention of performance data with no link
- Link goes to a completely unrelated page

## Notes

- The DfE rebranded "Compare School Performance" to "School and
  College Performance" and changed the URL. Many school websites
  still link to the old domain which currently redirects. Schools
  should update to the new URL.
- New URL: https://www.find-school-performance-data.service.gov.uk/
- Old URL: https://www.compare-school-performance.service.gov.uk/
  (still redirects as of 2025-26)
- This requirement applies to all state-funded schools — both
  maintained and academies.
- Some schools publish their own performance summaries alongside the
  link. This is good practice but does not replace the link to the
  official service.
- Performance data for 2020 and 2021 was not published due to
  COVID-19. Schools may note this context.

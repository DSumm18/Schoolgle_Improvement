# Financial Benchmarking Link

## Legislation

- School Information (England) (Amendment) Regulations 2025
- Academy Trust Handbook 2025, Section 2.5

## Current References

Must link to the DfE Schools Financial Benchmarking service
(https://schools-financial-benchmarking.service.gov.uk/). The link
must be functional and direct to the correct service. An outdated
link to a predecessor service (e.g. the old DfE benchmarking tables)
is non-compliant.

## Review Frequency

Link should be checked annually to ensure it remains functional.
No formal review cycle required — the obligation is simply to
publish and maintain a working link.

## Required Content

1. A clearly labelled, working hyperlink to the DfE Schools Financial
   Benchmarking service
2. The link must be findable — typically on a finance, governance,
   or statutory information page
3. The link must resolve to the correct DfE service (not a broken or
   redirected URL)

## Quality Indicators

- Link is clearly labelled (e.g. "Schools Financial Benchmarking" or
  "Compare our school's finances")
- Brief explanation of what the benchmarking service shows and why
  parents/stakeholders might find it useful
- Link opens in a new tab so users stay on the school site
- Accompanied by a summary of the school's financial position
- Easy to find from the main navigation (not buried in a PDF)

## Red Flags

- No link to financial benchmarking anywhere on the website
- Link is broken or returns a 404 error
- Link goes to the wrong service or a generic DfE page
- Link is buried inside a downloadable PDF and not on a webpage
- Link goes to the old benchmarking site that has been decommissioned

## Rating Descriptors

### Compliant (80-100)

- Working link to the DfE Schools Financial Benchmarking service is
  published on the school website
- Link is clearly labelled and easy to find
- Link resolves correctly to the benchmarking service

### Partial (40-79)

- Link exists but:
  - Is broken or redirects incorrectly
  - Is buried in a PDF document rather than on a webpage
  - Goes to a generic DfE page rather than the specific benchmarking service
  - Is present but poorly labelled (unclear what it links to)

### Not Found / Non-Compliant (0-39)

- No link to financial benchmarking found on the website
- Only a textual reference to benchmarking with no actual link
- Link goes to a completely unrelated service

## Notes

- This is primarily an academy requirement under the Academy Trust
  Handbook 2025, though maintained schools are also encouraged to
  publish the link.
- The DfE Schools Financial Benchmarking service URL is:
  https://schools-financial-benchmarking.service.gov.uk/
- Some multi-academy trusts publish this link on the trust website
  rather than individual school sites. Both approaches are acceptable
  as long as the school's page links to it or to the trust page.
- This is a simple binary check in most cases — the link either
  exists and works, or it does not.

# Ed Asset Pack for Schoolgle

This is a starter pack for Ed, the Schoolgle assistant.

## Core rules
- Warm amber gold is the default primary colour.
- Keep the base silhouette consistent.
- Readability at 32px matters.
- Seasonal changes should be overlays, not full redesigns.
- Ed is competent first, personality second.

## Folder guide
- core: main logo assets
- states: UI state swaps
- expressions: reaction variants
- seasonal: themed assets
- badges: reusable badge assets
- animation: starter specs
- png: raster versions
- voice: prompt, response bank and trigger map
